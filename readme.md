# Trabajo Práctico - Desarrollo Web

## 📌 Descripción
Este proyecto corresponde a un Trabajo Práctico de desarrollo web utilizando HTML y CSS. El objetivo es construir una página web estructurada, estilizada y publicada mediante GitHub Pages.

## 🚀 Tecnologías utilizadas
- HTML5
- CSS3
- Google Fonts

## 📁 Estructura del proyecto

- /css/styles.css
- /img (opcional)
- README.md
